# 路线图（状态说明，不是承诺）

DS-link 的当前能力和未来方向分开写，不把愿景当成已经实现。品牌改名不自动升级日用安装；当前没有公开 npm 包或 Release。

## 现在：本机 link

当前只连接**同一个 DSH 宿主中已登记的会话**，可以跨工作区，不连接另一台电脑、团队网络或全网 Agent。

现在可用的功能：

- 从源码构建并通过 DSH 官方插件入口安装（见[安装说明](installation.md)）。
- 会话发现、发送通知/请求、显式关联回复、状态查询和带首条任务的会话创建。
- 气泡与卡片两种显示；卡片模式不需要 Host 桥接。
- 完整气泡流、本轮统计、Agent 提示和引用操作，**在匹配的 Host 桥接下**可用。
- 设置/记录面板、暂停投递、并发通道、回复等待和已完成正文保留。
- 引用图标、往返记录和合成演示素材。

## 未来探索：团队内 link / 全网 link

- **团队内 link**：探索团队成员或设备之间的协作连接。具体接入范围、身份和权限需要另行设计；不等于现有 DSH Team 子代理功能已经实现跨机器通信。
- **全网 link**：探索 Agent 邮箱式的地址与消息往来。当前没有公网收件、远程发现或邮件协议实现，不把本地控制面直接暴露为公网服务。
- **顺序未冻结**：可以先探索团队，也可以先探索全网；不是已排期功能。真正实施前明确身份验证、隐私、投递与滥用防护边界。

Local links work today. Team links and global Agent mailbox-style links are future directions, not implemented capabilities. Their priority and design are not frozen.

## 已知限制

- 本批完整 UI 只在 DSH `0.2.2-rc.1` + 精确桥接、Linux Web、Node 24、Chromium 上验证。
- 通信层按历史版本支持 `0.2.1-rc.5` / `0.2.2-rc.1`，但不等于完整 UI 在 `rc.5` 上已验收。
- macOS、Windows、桌面客户端、其他浏览器和其他 Host/Node 版本未承诺完整支持。
- 完整气泡桥接是源码内、单独授权的 Host 维护工具；不随插件包分发，不自动安装，升级后可能被覆盖；没有桥时气泡退回旧的节点皮肤，不是完整体验。
- 记录页没有逐链 pause/resume/close 按钮；跨版本账本/待投递/回滚兼容未验证。
- 按名称复用或自动续跑的子 agent、实时回执观察、旧滚动保护等路径仍有不确定性；未确认状态不能当成成功。
- rc.1 用户子槽可能影响其他插件注入的装饰；组合使用前需单独验证。

## 未承诺

- 公开 npm 包或公开 Release 的具体时间、版本号或下载地址。
- 自动发布、自动安装、自动重启、自动改写历史或自动修改生产 profile。
- 其他操作系统、桌面端、全部浏览器或全部 DSH/Node 版本的完整支持。
- 团队/全网 link 的具体架构、协议、上线时间，以及 Bot 团队平台、任务 DAG、自动替用户审批或逐目标同意机制。
- 把路线图当成已排期承诺。欢迎通过 Issue 说明真实场景和改进方向；是否实施、何时实施由维护者另行判断。
