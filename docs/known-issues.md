# 已知限制与排障

[English](known-issues.en.md) · [安装](installation.md) · [首页](../README.md)

| 现象 / 限制 | 怎么处理 |
| --- | --- |
| 安装插件后，过程仍分散或 Agent 提示不完整 | 原生 Host 缺少完整气泡接缝；先核对[兼容矩阵](installation.md)，不要把陌生版本的 bundle 强行打补丁 |
| 不想修改 Host | 使用卡片模式；气泡仍可能回退为旧节点皮肤，不能据演示推断完整支持 |
| 宿主升级后气泡变化 | 桥接可能被覆盖；重新检查，哈希不匹配就停止，不自动重装旧桥 |
| 我发的消息没有一键引用图标 | 当前新增按钮只接在助手消息动作槽；用户正文可选中后用宿主“引用文本” |
| 引用里只有前一部分 | 1200 字符节选规则；需要后文时选中具体段落引用，不假定模型看到了未引用内容 |
| 引用框里有 Markdown 标记 | 引用的是源文本以保留格式，预览不承诺富文本排版 |
| Agent 小提示没把某次复用算进去 | 按名称复用、自动续跑缺少稳定身份时不猜；灰色是不确定，不一定失败 |
| 会话忙碌，消息没立即出现 | 等待步骤边界；不会打断当前工具批，亦没有承诺忙时最大延迟 |
| unknown / 超时 | unknown 不自动重发；超时不撤销工作。核对目标和状态后再决定 |
| 某组通信暂停后找不到恢复按钮 | 目前没有逐链 pause/resume/close UI；通过已有工具/owner 控制面处理，不是全局开关 |
| 其他插件的用户消息装饰消失 | rc.1 用户子槽适配可能屏蔽 before 装饰；与 liveshare 等组合前须单独验证 |
| 回执长期不更新 | 实时观察异常可能失去回执；不要把排队解释成已读，保留记录并报告问题 |
| 页面跳动或旧浏览器异常 | rc.1 旧滚动补丁未全部迁移；完整桥使用 CSS @scope，主要验证 Chromium，其他浏览器需单独验收 |
| 想退回旧包 | 包与配置备份只是恢复材料；新账本/待投递数据的跨版本降级尚未证明安全 |

## 安装报告需要什么

插件版本、DSH 版本、Node、OS/浏览器、显示模式、是否单独安装桥接、最小复现。只提交脱敏日志。用[安装问题模板](https://github.com/Wangmo-bit/dsh-session-link/issues/new?template=install.yml)，不要贴登录地址、token 或私人会话。

未复现的现象不要通过自动刷新、反复重发、手工编辑已装包来掩盖。模型服务延迟与工具执行耗时也不等于插件消息转发延迟。
